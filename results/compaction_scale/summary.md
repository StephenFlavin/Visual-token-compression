## Post hoc (not pre-registered): the hook bug and the fixed hook

10 of B's 14 misses were `def`-line questions on 7 files the Python minifier refused (they contain its own marker characters § and »). For those files the first hook fell back to flowed text and dropped the line numbers. The fixed hook keeps a §n tag on every line in that fallback. Arm `Bfix` repeats B on the 3 code sessions (new fork, new compaction, same questions):

* code questions: D 100.0%, B 91.7%, Bfix 100.0%; task items 100%; answering $1.12 for 3 sessions
* all 360 questions with Bfix for the code sessions: 98.9%, vs D -1.1 points (-2.8 to +0.1), p = 0.12
* cost with the fixed hook (B for research and logs, Bfix for code; compaction charged as above): $1.85 per session after reading, $0.0414 per correct answer (2.17x cheaper than normal compaction)
